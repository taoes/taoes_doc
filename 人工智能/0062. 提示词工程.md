**提示词工程（Prompt Engineering）**，简单来说，就是**设计和优化给AI（尤其是大语言模型）的输入指令，以引导它输出你想要的、高质量的结果**。

它不是编程，更像是一门“沟通”的艺术——你不需要写代码，而是要用自然语言，精准地告诉AI“你要做什么、怎么做、以及不要做什么”。

---

## 🎯 为什么需要提示词工程？

大模型就像一个知识渊博但“过于听话”的天才助手。如果你问得模糊，他可能给你一个泛泛而谈的答案；如果你问得精准，他就能给出惊艳的回复。

**对比示例：**

| 提示词类型       | 提示词内容                                                                                                    | AI回复质量                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| ❌ **糟糕的提示** | “写一篇关于AI的文章”                                                                                          | AI可能写出一篇泛泛的、结构混乱、没有深度的大路货文章。 |
| ✅ **好的提示**   | “你是一位AI领域教授，请为科技新手写一篇800字的科普文章，介绍大语言模型的工作原理，包含生活化比喻，语气亲切。” | AI会输出一篇有结构、有比喻、面向特定受众的专业文章。   |

## 🧩 提示词的核心构成要素

一个高质量的提示词，通常包含以下要素：

```textile
┌─────────────────────────────────────────┐
│  1. 角色 (Role)                         │
│     → "你是一名资深Python工程师"         │
│  2. 任务 (Task)                         │
│     → "请写一个Web爬虫代码"              │
│  3. 上下文 (Context)                    │
│     → "目标网站是豆瓣Top250，需防反爬"   │
│  4. 格式 (Format)                       │
│     → "以JSON格式输出，包含标题和评分"    │
│  5. 约束 (Constraints)                  │
│     → "代码要添加中文注释，不超过100行"   │
│  6. 示例 (Examples)                     │
│     → 给几个输入输出的样例               │
└─────────────────────────────────────────┘
```
