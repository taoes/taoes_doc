## 1、通过 Docker 安装 Dify

```shell
git clone --branch "$(curl -s https://api.github.com/repos/langgenius/dify/releases/latest | jq -r .tag_name)" https://github.com/langgenius/dify.gitcd dify/docker
cd dify/docker
cp .env.example .env
docker compose up -d
```

## 2、安装配置 Dify

浏览器打开 `http://localhost:80/install` 



## 3、创建应用，使用 Python 执行

```python
import json
import requests

body = {
    "inputs": {
        'content': '你好，我今天很很高兴，因为我的数学城际是一百分'
    },
    "user": "customer-4821",
    "response_mode": "blocking",
}

token = 'app-XHzhyu8bbjiFyY9UpldbW2TX'
url = 'http://localhost/v1/workflows/run'
headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json'
}
print(headers)
data = requests.post(url, headers=headers, json=body, stream=False)
print(json.loads(data.content))
```
