### **零样本思维链 (Zero-shot CoT)**

不提供示例，只用一句魔法指令："Let's think step by step"（让我们一步步思考）。

```python
prompt = """
用户咨询：手机充不进电，已经试过换充电线了。

作为技术客服，请一步步分析可能的原因和解决方案。
"""

# 或者加一句魔法短语
prompt += "\n让我们一步步思考这个问题。"
```

### 2. **少样本思维链 (Few-shot CoT)**

提供2-3个完整的"问题→推理过程→答案"示例，让AI模仿推理模式。

```python

- 设女生人数为x
- 男生人数为x+4
- 总人数：x + (x+4) = 32

- 男生 = 14+4 = 18
```

### 4. **自我一致性 (Self-Consistency)**

让AI多次推理（通过温度参数采样），然后投票选最优答案。

```python
# 伪代码
answers = []
for i in range(5):  # 生成5次推理
    response = llm.generate(prompt, temperature=0.7)
    answers.append(parse_answer(response))

# 投票：选择出现次数最多的答案
final_answer = majority_vote(answers)
```

**适用场景**：数学推理、复杂决策等有唯一正确答案的任务。

### 5. 树状思维链 (Tree-of-Thought, ToT)

在每一步探索多个可能分支，而不是线性推进。

```textline
问题：如何提高电商转化率？

Step 1 探索分支：
├─ 优化用户体验 → 继续探索
│   ├─ 简化支付流程
│   ├─ 增加用户评价
│   └─ 优化移动端
├─ 营销策略 → 继续探索
│   ├─ 限时折扣
│   ├─ 会员体系
│   └─ 社交媒体投放
└─ 数据分析 → 继续探索
    ├─ A/B测试
    ├─ 用户行为分析
    └─ 购物车遗弃挽回
```

## 📊 CoT的高级变体

| 技术名称               | 说明              | 适用场景               |
| ---------------------- | ----------------- | ---------------------- |
| **Zero-shot CoT**      | 加"一步步思考"    | 快速验证，通用场景     |
| **Few-shot CoT**       | 提供推理示例      | 特定领域，需提升准确率 |
| **Self-Consistency**   | 多次采样投票      | 数学、逻辑推理         |
| **Tree-of-Thought**    | 多分支探索        | 创意生成、复杂规划     |
| **Plan-and-Solve**     | 先规划再执行      | 长任务分解             |
| **ReAct (Reason+Act)** | 推理+工具调用交替 | Agent任务执行          |

## ⚠️ CoT实践的注意事项

### 1. **输出长度控制**

```python
# 要求推理简练
prompt = "请用最多3句话展示推理过程，然后给出答案。"
```

### 2. **防止幻觉**

```python
# 要求模型明确不确定性
prompt = "如果推理过程中有不确定的地方，请标注'[不确定]'。"
```

### 3. **成本控制**

```python
# 复杂问题用CoT，简单问题直接回答

if problem_complexity > threshold:
    use_cot()
else:
    direct_answer()
```

### 4. **解析推理结果**

```python
# 用正则或关键词提取最终答案
import re
response = llm.generate(cot_prompt)

# 提取"答案："后面的内容

final_answer = re.search(r"答案[：:]\s*(.+)", response).group(1)
```

### 5. **隐私与安全**

- 不要让AI在推理中暴露敏感信息
- 对推理过程做脱敏处理

```python
class CoTAgent:
    def __init__(self, llm):
        self.llm = llm
    
    def think_and_act(self, user_input):
        # Phase 1: 思维链推理
        thought_prompt = f"""
        用户输入：{user_input}
        
        请按以下步骤推理：
        1. 用户核心需求是什么？
        2. 需要调用什么工具？
        3. 工具调用的参数是什么？
        4. 如果信息不足，需要追问什么？
        """
        
        thoughts = self.llm.generate(thought_prompt)
        
        # Phase 2: 提取行动
        action = self.parse_action(thoughts)
        
        # Phase 3: 执行工具
        result = self.execute_tool(action)
        
        # Phase 4: 生成回答
        final = self.llm.generate(f"""
        基于推理过程：{thoughts}
        工具执行结果：{result}
        请生成给用户的最终回复。
        """)
        
        return final
```
